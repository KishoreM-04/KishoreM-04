> A modern cross-platform mobile application engineered with Flutter to power the Dignito College Festival. Streamlines event discovery, participant registrations, live schedule timelines, and fest coordinator communications into a fluid, animated mobile experience.

---

## ✨ Capabilities

- **Interactive Event Catalog:** Browse technical, cultural, and gaming competitions with criteria, rules, venue details, and registration fees.
- **Dynamic Registration Pipeline:** Collects participant credentials, institution details, and team member rosters with local validation.
- **Live Timeline & Schedule:** Real-time schedule viewer displaying ongoing and upcoming events to keep attendees informed throughout fest days.
- **Fluid Material 3 Interface:** Customized theme matching the Dignito festival branding with smooth transition animations and responsive layouts.

---

## 🛠️ Technology Stack

- **Framework:** Flutter (Version 3.x)
- **Language:** Dart
- **State Management & UI:** Flutter Material 3, Custom Scroll Views, Responsive Layout Builders
- **Build Targets:** Android (APK / App Bundle), iOS

---

## ⚡ Running the Application Locally

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed and configured on your PATH.
- Android Studio / VS Code with Flutter and Dart extensions.

### Steps
1. Clone this repository:
   ```bash
   git clone https://github.com/KishoreM-04/Dignito-Fest-Management-App.git
   cd Dignito-Fest-Management-App/dignito
   ```
2. Fetch dependencies:
   ```bash
   flutter pub get
   ```
3. Run on a connected Android phone, iOS simulator, or Chrome:
   ```bash
   flutter run
   ```
