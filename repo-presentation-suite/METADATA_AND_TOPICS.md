## 🛠️ Step-by-Step GitHub Web UI Guide to Apply Metadata

### Step 1: Update Repository Descriptions and Topics
1. Navigate to the repository on GitHub (e.g. `https://github.com/KishoreM-04/TaskFlow`).
2. On the top right of the repository homepage, click the **⚙️ (Edit repository details)** cog next to "About".
3. Paste the **Recommended Description** from the table above.
4. Add the **Topics** one by one.
5. In the **Website** field, add your portfolio link: `https://kishorem-04.github.io`.
6. Click **Save changes**.

### Step 2: Configure Pinned Repositories on Your Profile
1. Navigate to your public GitHub profile: `https://github.com/KishoreM-04`.
2. Scroll to the "Popular repositories" or "Pinned" section.
3. Click **Customize your pins** (or click the three dots icon / Edit pins).
4. Select the 6 repositories in the order recommended above.
5. Click **Save pins**.

### Step 3: Enable GitHub Pages for the Portfolio Website
1. Go to `https://github.com/KishoreM-04/KishoreM-04/settings/pages`.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Under **Branch**, select `main` and choose the `/docs` folder.
4. Click **Save**. Within 60 seconds, your interactive portfolio will be live at `https://kishorem-04.github.io/`!
